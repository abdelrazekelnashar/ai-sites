# AI Bookmark Manager

A sleek web app to organize and manage AI site bookmarks. 

This project uses a frontend built with HTML, CSS, and JavaScript, which is served via a simple Streamlit application.

*Live Demo:* [https://ai-sites.streamlit.app/](https://ai-sites.streamlit.app/)

## Getting Started

To run this application locally, you will need Python and Streamlit installed.

1. Ensure you have Streamlit installed:
   ```bash
   pip install streamlit
   ```

2. Run the application:
   ```bash
   streamlit run app.py
   ```

This will launch a local server and open the web application in your default browser.
